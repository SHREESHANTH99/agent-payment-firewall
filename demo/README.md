# Agent Payment Firewall - Demo Scenarios

Placeholder directory for interactive AI agent simulation scripts and payment firewall test scenarios.

## Planned Scenarios
1. **Compliant Purchase**: Agent requests a payment within mandate budget and allowable merchant list; intent is automatically approved and executed via PayPal sandbox payout.
2. **Policy Violation**: Agent exceeds per-transaction cap or targets an unapproved merchant; payment intent is immediately blocked.
3. **Escalation & Anomaly**: Ambiguous reasoning or high-value intent triggers human-in-the-loop escalation workflow.
