# Agent Payment Firewall - Dashboard

Next.js + TypeScript dashboard placeholder for managing autonomous AI agent spending mandates, monitoring payment intents in real-time, reviewing automated risk evaluations, and inspecting cryptographic audit logs.

## Upcoming Features
- **Mandate Management**: Configure budgets, per-transaction limits, allowed merchants, and validity windows for AI agents.
- **Intent Stream**: Real-time view of intercepted agent payment requests (Pending, Approved, Escalated, Denied, Executed, Failed).
- **Risk Analysis**: Visual inspector for deterministic policy evaluation and LLM hallucination / anomaly detection.
- **Audit Ledger**: Hash-chained immutable trail of payment approvals and PayPal execution batches.
